# Glass implementation research

The human requested inspection of working GitHub implementations after rejecting the first rounded/translucent candidate. Actual source and license files were inspected, not only repository images. Read-only clones and exact snapshots are retained in local evidence. No upstream package, scene, dependency or example script was imported into the Player.

Apple primary guidance and visual examples remain the design reference: [visionOS](https://developer.apple.com/design/human-interface-guidelines/designing-for-visionos), [materials](https://developer.apple.com/design/human-interface-guidelines/materials), [Liquid Glass](https://developer.apple.com/documentation/technologyoverviews/liquid-glass). The translation is restrained material depth and readable hierarchy, rather than a claim of identical proprietary Apple rendering.

The implemented RenderGraph pass follows the installed Unity6000.6/URP17.6 API and was checked against its CopyColorPass/Blit source. Render-graph capture, separable Gaussian filtering, SDF rounded rectangles, Snell refraction and Schlick-style Fresnel are standard techniques. Our implementation is original; no substantial upstream code or assets are redistributed. Full upstream licenses remain in the local research clones.

Verification must include a detailed scene background, same-tint diffusion-off control, actual changing scene response, diffusion-on/off GPU readback, refraction-on/off bevel response, transparent empty-scene alpha, clipping/large text, and cumulative interaction/native mapping/build gates. These are not claims of headset acceptance or physical-room blur.
