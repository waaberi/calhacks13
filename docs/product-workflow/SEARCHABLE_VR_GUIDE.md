# Searchable VR Guide

Choose **Guide** on the left-hand menu. Use its local keys to enter a topic such as `rotate`, `plane`, `input`, `undo` or `extrude`. Partial words also match. Select a result to read the written steps; use **Next step**, **Previous step** and **Back to search**. Clear search to browse all topics, and use the topic-page buttons to reach the full collection.

The Guide explains the current controls and prerequisites. It never selects a tool, edits geometry, sends a Blender key, submits a voice command or calls an AI service. Blender remains the modeling tool menu. Its existing native keyboard remains available for typing into Blender.

Finish an active gesture, native modal, input transition or voice confirmation before opening help. Opening does not cancel those operations. Idle Input ON can remain enabled while reading. Close Guide before continuing with an edit. A Guide press is consumed until its trigger is released so that closing cannot click the model beneath it.

The panel anchors in front of the current view when opened and stays there while reading. Text and targets respect the existing accessibility text-size setting. Search and written-step pagination remain local. Unsupported features and their native 2D alternatives are described explicitly; finding an article does not make an unavailable direct gesture executable.

The 33 topics cover direct transforms, multi-selection, axis constraints, surface-supported scaling, mesh editing tools, snapping/proportional settings, live acknowledgements and history, native 2D editing/keyboard/input handoff, voice chains/Gemini review, saved room/manual planes, workspace arrangement and appearance. Proposed workspace voice commands are not included.

Software routing and synthetic text checks are separate from headset readability/controller acceptance. Current room-fit and untested direct-tool physical checks remain pending. No automatic runtime switch is part of adding this Guide.
